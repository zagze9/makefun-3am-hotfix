# 3 AM Hotfix — one-line commit message entry

This repository is an entry for the make.fun bounty
[3 AM Hotfix: The Funniest Commit Message](https://make.fun/bounty/u-yuki-kato-3-am-hotfix-the-funniest-commit-message-e9f60106).

It is a program/v1 entry: `main.ts` writes a single git commit message
(one line, under 180 characters, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, written as if by a developer who has
just fixed production at 3 AM:

```
hotfix: rolled back to Friday. Friday was also broken, but it broke slower.
```

Run it with Node 22+ (`node main.ts`, type-stripped) and read
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
